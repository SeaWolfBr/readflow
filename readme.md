# ReadFlow (versão estática)

Aplicação simples de treino de leitura, feita em **um único arquivo `index.html`**, sem API, sem backend e sem banco de dados.

## Modos disponíveis

- RSVP
- Foco
- Chunking
- Teste de Velocidade (com cronômetro e cálculo de PPM)

## Como usar localmente

1. Baixe ou copie a pasta do projeto.
2. Dê duplo clique em `index.html`.
3. O site abrirá no navegador.

## Como publicar no GitHub Pages (jeito simples)

1. Crie um repositório no GitHub.
2. Envie os arquivos do projeto (principalmente `index.html`).
3. No GitHub, abra **Settings > Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e pasta `/ (root)`.
6. Clique em **Save**.
7. Aguarde 1-2 minutos e abra o link gerado.

## Como publicar no Netlify (jeito simples)

1. Acesse netlify.com e faça login.
2. Clique em **Add new site** > **Deploy manually**.
3. Arraste a pasta do projeto para a área de upload.
4. Aguarde a publicação.
5. Abra o link que o Netlify mostrar.

Pronto: seu site estático ficará online sem configurações avançadas.
